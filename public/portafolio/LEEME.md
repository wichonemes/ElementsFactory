# Portada · Wicho Nemes (v2)

Portada de ocho áreas, sin la tarjeta independiente de Fotografía.

## Tarjetas y colores

| Área | Color |
| --- | --- |
| Identidad | dorado `#e8b84f` |
| Audiovisual | cian `#58c5d4` |
| Animación | rosa `#e879b8` |
| Ilustración | violeta `#9b8aff` |
| Modelado 3D | azul `#68a9ed` |
| Interfaces | verde `#6dc49a` |
| Impresos | naranja `#e99158` |
| Editorial | rojo `#e5675f` |

- Cada tarjeta lleva una franja inferior con el color de su área; ese mismo tono se usa en la pestaña activa, la barra flotante de áreas y la barra de progreso de cada página.
- **Fotografía** ya no es una tarjeta ni una pestaña independiente: se abre desde la **tarjeta final de Audiovisual** (`../fotografia/`), y en su página la pestaña activa es Audiovisual (cian).
- La portada se organiza en 4×2 tarjetas y se adapta a móvil sin desbordamiento horizontal.

## Cómo abrir

- Con el servidor local: `http://localhost:8765/maquetado-inicio-wicho-v2/`.
- El botón de administrar de la portada permite cambiar las portadas de las áreas; el **modo de edición visual** con lápices está en cada página de área.

## Marca

- La portada usa `assets/marca-wicho.png`, el mismo logo de las páginas de área, junto a **WICHO NEMES**.

## Acceso al editor

- El control de imágenes es el **engrane discreto** de la barra superior.
- Al pulsarlo se abre un acceso privado. El usuario es `wichonemes@gmail.com`; la contraseña se verifica localmente y no se guarda en texto plano.
- La sesión se mantiene mientras la pestaña esté abierta. El botón **Cerrar sesión** está al final del panel.
- Dentro del panel hay una opción **Cambiar contraseña**. El cambio se guarda solo en el navegador donde se hace; en otro dispositivo se usa la contraseña inicial.
- La opción **¿Olvidaste tu contraseña?** abre un correo dirigido a `wichonemes@gmail.com` y permite volver a la contraseña inicial en ese navegador. El envío automático de contraseñas requiere un servidor de correo.
- Es una barrera local del maqueta: no sustituye una autenticación de servidor para un sitio público.

## Foto de perfil

- La portada usa `assets/perfil-sin-fondo.png`, un PNG con fondo transparente.
- El original con fondo se conserva como `assets/perfil-con-fondo.png`.
- Si el navegador conserva una foto anterior elegida desde **Editar imágenes**, pulsa **Restablecer imágenes** para volver a la foto actual.

## Nota

Los cambios se guardan en el navegador. No se publican ni se sincronizan solos, y este rediseño no modifica Google Sites.
